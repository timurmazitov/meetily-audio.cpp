# 01: Единый сборщик имени файла и новые имена экспорта транскрипции

**What to build:** Экспорт транскрипции в обоих местах — в карточке встречи и в панели живой записи — предлагает имя файла вида `20261118-Планёрка_по_релизу-transcript.txt` вместо текущего `<название>.txt`.

Имя собирается одной функцией для обоих вызовов: дата в формате `YYYYMMDD` берётся из локальной даты создания встречи (в панели живой записи, где встречи ещё нет в базе, — из текущего момента; невалидная дата тоже откатывается к текущему моменту), затем нормализованное название встречи, затем суффикс `transcript`, затем расширение. Название нормализуется для файловой системы без потери читаемости: запрещённые символы и переводы строк заменяются на `_`, последовательности пробелов — на `_`, повторные `_` схлопываются, ведущие и хвостовые `_` обрезаются, кириллица и регистр сохраняются, слишком длинное название обрезается до 60 символов по границе символа, пустое название превращается в `meeting`. Расширение дозаписывается, если его нет в имени по умолчанию; вручную введённое пользователем расширение не переписывается.

Нейтральный модуль сборки имени заменяет прежний хелпер, названный по транскрипции; оба места экспорта переходят на него, чтобы правила даты и нормализации больше не дублировались.
