# 02: Полное название встречи в строке с датой окна саммари

**Parent:** `.scratch/meeting-title-display-export/spec.md`

**What to build:** В окне текста саммари, в строке где сейчас показана только дата, слева появляется полное название встречи как главный заголовок: элемент `h1`, чёрный цвет, размер и насыщенность как у принятого в приложении заголовка встречи (`text-2xl font-bold`), перенос по словам без обрезки. Дата остаётся справа в прежнем виде (серый, табличные цифры, без переноса) и остаётся единственным элементом с табличными цифрами в строке. Название читается и когда дата встречи неизвестна; при неизвестной дате дата не показывается и не подменяется текущим моментом (ADR-0005).

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] В строке окна саммари слева отрендерен `h1` с полным названием встречи, классы: чёрный цвет, `text-2xl`, `font-bold`, без обрезки и без `line-clamp`/`truncate`
- [x] Дата справа сохранена в текущем стиле (серый, `tabular-nums`, без переноса); в строке ровно один элемент с табличными цифрами
- [x] Длинное название переносится на несколько строк и выводится целиком
- [x] При неизвестной/непарсильной дате название показывается, дата — нет (ни заглушки, ни текущего момента)
- [x] Название не появляется в шапке панели транскрипции и не дублируется при смонтированных обеих панелях (split view с `forceMount`)
- [x] Тесты на шве прямой панели саммари (расширяем существующий набор про дату встречи): наличие и классы заголовка, текст, поведение без даты, отсутствие дублей; моки Radix-обёрток — как в существующем наборе
- [x] Тестируется внешний вид и текст, не внутренние пропсы; тесты на существующем раннере и приёмах
- [ ] Живая проверка в Tauri-приложении: длинное и короткое названия, встреча без даты; в отчёте указано, что запускалось и что осталось непроверенным
