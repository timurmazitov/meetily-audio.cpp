# 03: Попап с полными данными встречи при наведении в списке

**Parent:** `.scratch/meeting-title-display-export/spec.md`

**What to build:** Пользователь наводит курсор на строку встречи в списке слева — появляется всплывающая подсказка с полными данными: полное название без обрезки, дата и время встречи, длительность встречи, «Спикеров: N». Подсказка показывается при наведении на любую строку встречи, включая короткие названия. Форматтеры даты+времени и длительности переиспользуются те же, что уже применяются в строке списка и в окне саммари, с учётом языка интерфейса. Количество спикеров берётся из существующего API диаризации: подгружается при первом наведении и кэшируется на время сессии сайдбара. Подписи — через существующую i18n-систему, переводы для обоих языков интерфейса. Двухстрочная обрезка названия в самой строке остаётся как есть — подсказка дополняет её, а не заменяет.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Строка с неизвестным значением не выводится вовсе; при нуле или неизвестном количестве спикеров строки про спикеров нет (в том числе при ошибке запроса — без нуля и без поломки строки)
- [x] Терминология по глоссарию: «Спикеров», а не «участников»
