# 01: Экспорт использует актуальное название встречи после переименования

**Parent:** `.scratch/meeting-title-display-export/spec.md`

**What to build:** Пользователь открывает встречу, генерирует саммари, переименовывает встречу в сайдбаре и нажимает «Экспортировать». Файл сохраняется с новым названием встречи, и заголовок внутри файла (`# Meeting Summary:` для саммари, `# Transcript of the Meeting:` для транскрипции) тоже новый. То же для копирования в буфер: скопированный текст совпадает с экспортируемым, включая новое название. Открытая страница встречи сразу показывает новое название без перезагрузки. Чинится источник: локальное состояние названия на странице встречи синхронизируется с данными встречи, а сайдбар при любом успешном сохранении из диалога редактирования уведомляет открытую страницу существующим событием обновления метаданных.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] После переименования в сайдбаре экспорт саммари передаёт в системный диалог сохранения имя файла `<YYYYMMDD>-<новое название>-summary.md` (санитизация и правила имени — существующие)
- [x] После переименования экспорт транскрипции передаёт имя файла с новым названием
- [x] Заголовок `# Meeting Summary:` внутри экспортируемого файла — с новым названием; аналогично заголовок транскрипции
- [x] Копирование саммари/транскрипции в буфер даёт текст с новым названием (совпадает с экспортом)
- [x] Переименование только названия (без даты) тоже вызывает уведомление открытой страницы; обновление затрагивает метаданные, без перезагрузки транскрипций и списка спикеров
- [x] Автоназвание от генерации саммари продолжает обновлять и список, и открытую страницу; синхронизация идемпотентна и не откатывает только что выставленное значение
- [x] Переименование не сбрасывает дату и длительность встречи
- [x] Сквозной тест на главном шве (сайдбар + маршрут встречи под моками Tauri-границы): rename через диалог строки → «Экспортировать» → новый `defaultFileName` и новый заголовок в теле; отдельный кейс для экспорта транскрипции
- [x] Тестируется внешнее поведение, не приватные поля хуков; тесты на существующем раннере и приёмах (`react-test-renderer` + `act`, `mock.module`), без новой инфраструктуры
