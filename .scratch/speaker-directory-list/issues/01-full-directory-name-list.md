# 01: Полный справочник людей в панели Speakers, по алфавиту

**What to build:** Пользователь открывает выпадающий список имён для спикера в панели Speakers и видит **всех** людей из глобального справочника, а не ограниченную подборку из восьми имён. Список отсортирован по алфавиту — кириллица А-Я, затем латиница A-Z, затем всё остальное (цифры, прочие алфавиты), без учёта регистра. Список прокручивается, сужается по мере набора текста мгновенно, без сетевой задержки. Пункты **No name** и **Create «X»** закреплены сверху; «Create» появляется только когда точного совпадения нет.

Этот тикет единственный меняет контракт списка имён: ограниченная подборка имён уходит из ответа панели спикеров, параметризованный поиск с лимитом исчезает, появляется одна узкая команда «дай весь справочник» — без поисковой подстроки, без лимита и без гарантии порядка. Правило сортировки выделяется в единственный общий компаратор, которым затем будет пользоваться и дропдаун чипа. Фильтрация переносится на клиент, поэтому задержка ввода и гонки запросов исчезают.

Справочник читается один раз при открытии панели и перезапрашивается после успешного сохранения, потому что **Done** мог создать новое имя. Ошибка чтения справочника не блокирует работу: **No name** и создание из введённого остаются доступны, а сообщение об ошибке показывается внутри открытого списка.

Документация поведения имён спикеров приводится в соответствие с новым контрактом, а в словарь предметной области добавляется понятие «справочник людей», которое спецификация использует как самостоятельное.
