# 02: Занятые имена недоступны для выбора

**What to build:** Пока в панели Speakers подбираются имена для нескольких спикеров одной встречи, человек, уже назначенный другому спикеру, виден в списке, но выбрать его нельзя: строка показана серой, не реагирует на выбор и поясняет, какому спикеру этот человек принадлежит. Ограничение видно заранее, а не всплывает сообщением об ошибке после **Done**.

Сравнение имён идёт по тем же правилам, что и на бэкенде: с обрезкой внешних пробелов и без учёта регистра, включая кириллицу. Учитывается текущий черновик панели, а не только сохранённое состояние, поэтому переприсвоение имени между строками остаётся возможным: спикер, которому имя принадлежит в черновике, сохраняет это имя доступным. Правила конфликта на бэкенде не меняются — блокировка в интерфейсе дополняет их и не подменяет.

## Comments

- Ветка: `ticket/02-blocked-names-in-picker`, влита merge-коммитом `29030e4`; конфликтов не было.
- Занятость считается по черновику панели (`nameOwners`: свёрнутое имя → строки-владельцы), а не по сохранённому состоянию. Строка блокируется, только если все владельцы — другие строки, поэтому владелец в черновике сохраняет имя доступным.
- Сравнение — `personNameKey` (trim + `toLowerCase`, кириллица включена), общее с бэкендом правило. Заблокированный пункт — `disabled` в cmdk: визуально серый, не реагирует на выбор и пропускается клавиатурой, рядом подпись «какому спикеру принадлежит» (`data-testid="name-owner"`).
- Фильтрация и алфавитный порядок не изменились: `matches` считается до блокировки. Правила конфликта на бэкенде не тронуты.
- Осознанно не трогали строку **Create «X»**: блокировка по тикету относится к справочнику, а существующий тест намеренно проверяет, что дубль набранного имени доходит до бэкенда и получает его сообщение.
- Следствие блокировки: обмен именами двух строк в один проход невозможен, нужен промежуточный «No name». Это прямое следствие требования спеки блокировать занятое имя; сочтено допустимым.
- Проверка: `bun test tests/components/speakers-panel.test.tsx` — 36 pass / 0 fail; `bun test` — 354 pass / 12 fail (baseline); `bunx tsc --noEmit` — exit 0. Rust не менялся.
