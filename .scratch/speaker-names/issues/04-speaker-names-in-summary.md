# 04: Имена спикеров во входе саммари

Type: task
Status: resolved
Blocked by: 01

## Что сделать

Передавать имена спикеров в текст, который уходит на саммаризацию.

- `frontend/src/hooks/meeting-details/useSummaryGeneration.ts:376-390` (`buildSummaryTranscriptPayload`): строка сегмента становится `[MM:SS] <подпись>: text`, где подпись — имя, иначе `Speaker N`, иначе префикса нет — та же функция подписи, что в тикете `03` (переиспользовать, не дублировать логику).
- `transcriptTexts` (массив «сырых» текстов) не меняется — он используется отдельно.
- Ничего не менять в бэкенде саммаризации: fingerprint кэша считается по итоговому тексту (`frontend/src-tauri/src/summary/service.rs:131`), поэтому смена имён инвалидирует кэш сама.
- Существующие саммари не перегенерируются: изменение действует только на новые генерации.

## Тесты (TDD)

- Если функция подписи вынесена в `frontend/src/lib/transcript-format.ts`, покрыть её один раз и переиспользовать в тестах тикета `03`, не дублируя кейсы.
