# 02: Команды назначения имён и справочник для подсказок

Type: task
Status: resolved
Blocked by: 01

## Что сделать

Реализовать четыре Tauri-команды и всю валидацию имён на бэкенде.

- `api_get_meeting_speakers(meeting_id)` → `[{label, speaker_name, segment_count, first_start_time, top_speaker_names}]`. Зарегистрировать в `frontend/src-tauri/src/lib.rs` рядом с другими `api_*`.
- `api_assign_meeting_speakers(meeting_id, assignments)` — пакетное сохранение из **Done**. `name: null` = снять имя; непустое имя = привязать к существующему (совпадение `trim` + `NOCASE`) или создать новую запись справочника. Всё в одной транзакции: либо применяются все назначения, либо ни одно.
- `api_set_transcript_speaker(transcript_id, label | null)` — правка одной реплики, `null` = «No speaker». `meeting_speakers` не трогает.
- `api_get_speaker_names(query, limit)` → `[{id, name, meeting_count}]` — справочник для подсказок, сортировка по `meeting_count` убыв., затем по имени.

Правила (см. `.scratch/speaker-names/spec.md`, «Правила ввода имени»):

- `trim`, затем длина 1–100; пусто → ошибка валидации, а не «снять имя».
- Совпадение без учёта регистра → используем существующую запись, регистр первого ввода сохраняется.
- Два спикера одной встречи на одного человека → ошибка с текстом вида «этот человек уже сопоставлен спикеру Speaker 1».
- После транзакции удалить записи справочника, на которые больше не ссылается ни одна встреча (сироты).
- Поднять `meetings.updated_at` — как в `frontend/src-tauri/src/database/repositories/meeting.rs:187`.
- Метки не из шаблона `speaker_N` в назначение не принимаются.

## Тесты (TDD)

Инлайн `#[cfg(test)]` в `speaker.rs` / тестах команд:

- создание нового имени и повторное использование существующего (`Alex` → `alex` даёт ту же запись);
- «Без имени» удаляет привязку и затем сироту справочника;
- отказ при двух спикерах встречи на одного человека, транзакция не оставляет частичных изменений;
- длины 0, 1, 100, 101 символ; имя из одних пробелов;
- `api_set_transcript_speaker` не меняет `meeting_speakers` и корректно снимает метку;
- `updated_at` встречи изменился.
