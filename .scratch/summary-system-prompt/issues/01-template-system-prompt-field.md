# 01: Поле системного промпта в модели шаблона

Type: task
Status: ready-for-agent
Blocked by: —

## Что сделать

Добавить в модель шаблона опциональное поле собственного системного промпта (см. «системный промпт шаблона» в `GLOSSARY.md`).

- В структуру `Template` (`frontend/src-tauri/src/summary/templates/types.rs`) добавить опциональное строковое поле. Имя JSON-поля — в том стиле, в котором сериализуются остальные поля шаблона (проверить serde-атрибуты и JSON bundled-шаблонов в `frontend/src-tauri/templates/`); по умолчанию `None`/`null`, обязательности нет.
- Валидация шаблона (`validate`) не меняется: поле не валидируется по содержимому.
- Все существующие шаблоны (bundled JSON, built-in в `defaults.rs`) без изменений должны парситься как раньше (поле отсутствует → `None`).

## Тесты (TDD)

Рядом с кодом, в стиле существующих инлайн `#[cfg(test)]`:

- десериализация шаблона без поля → `None`;
- десериализация шаблона с заданным промптом → значение на месте;
- сериализация/десериализация roundtrip не теряет поле.
