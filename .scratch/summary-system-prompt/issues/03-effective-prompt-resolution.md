# 03: Разрешение эффективного промпта и подстановка плейсхолдеров

Type: task
Status: resolved
Blocked by: 01, 02

## Что сделать

- В модуле `system_prompt` (создан в тикете 02) реализовать:
  - разрешение эффективного промпта: системный промпт шаблона (если задан и непустой) → иначе базовый системный промпт из настроек (если непустой) → иначе константа дефолта. Полная замена, без конкатенации;
  - подстановку плейсхолдеров `{section_instructions}` и `{template}` в выбранный текст; плейсхолдер, отсутствующий в тексте, ничем не заменяется и никуда не дублируется.
- `processor.rs`: `build_final_report_system_prompt` перестаёт собирать текст сам — принимает уже выбранный «сырой» промпт и делает только подстановку плейсхолдеров. Встроенную копию дефолтного текста удалить (теперь она живёт в константе из тикета 02).
- `generate_meeting_summary` получает параметр базового промпта (`Option<String>` или аналог); точка вызова в `service.rs` пока передаёт `None` (проводка настройки — тикет 05). Код должен компилироваться.
- Затронуть только финальный отчёт: промпты чанк-саммари, комбайна, перевода, нормализации не менять.

## Тесты (TDD) — шов 1 из спецификации

- цепочка разрешения: задан шаблонный → он; пустой шаблонный + задан базовый → базовый; оба пустые → дефолт; пустая строка трактуется как «не задано»;
- полная замена: результат не содержит фрагментов базового промпта при заданном шаблонном;
- подстановка: оба плейсхолдера, только один, ни одного (текст уходит как есть);
- финальный системный промпт содержит инструкции секций и разметку шаблона вместо плейсхолдеров.
