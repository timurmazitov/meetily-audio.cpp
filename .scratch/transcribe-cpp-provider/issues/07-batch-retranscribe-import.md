# 07: Пакетные пути — ретранскрибация, импорт, выгрузка движка

**What to build:** Пользователь может перетранскрибировать существующую встречу или импортировать аудио файл провайдером Transcribe.cpp с точным указанием модели (без тихого фолбэка на другую установленную модель). После пакетной работы движок выгружается из памяти, если запись не идёт, и не мешает активной записи. Для всех batch-сценариев новый провайдер — полноценный участник наравне с тремя существующими.
