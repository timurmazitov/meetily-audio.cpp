# 03: Импортированная встреча показывает момент импорта и длительность файла

Type: task
Status: resolved
Blocked by: 02

## Что сделать

Путь импорта заполняет те же два поля, и в списке импортированная встреча показывает момент импорта и **длительность исходного файла**, а не конец последней реплики.

- Импорт сохраняет дату встречи = момент импорта (консистентно с `created_at` и с `metadata.json`, который пишет импорт).
- Длительность = длительность декодированного файла; она уже вычисляется в процессе импорта, нового вычисления не требуется.
- Вставка встречи дополняется двумя колонками.

Ограничения: `created_at`/`updated_at` пишутся как раньше; при отсутствии данных — `NULL`, не `0.0`. Срез не меняет поведение записи (тикет 02).

## Критерии готовности

- [x] Импортирую аудиофайл — в списке момент импорта и длительность исходного файла.
- [x] Длительность импортированной встречи больше длительности по последнему сегменту (файл длиннее речи).
- [x] Импорт встречи с неразбираемым/коротким файлом не падает и не пишет нули.
- [x] Тесты импорта зелёные.
