# 02: Записанная встреча показывает дату и длительность в списке

Type: task
Status: resolved
Blocked by: 01

## Что сделать

Первый сквозной срез: запись встречи → дата и длительность в списке. Проходит все слои, потому что показывать нечего, пока данные не хранятся и не отдаются.

**Хранение.** Миграция `20261119000000_add_meeting_recorded_at_and_duration.sql`: `recorded_at TEXT` и `duration_seconds REAL`, обе nullable, без `DEFAULT`. `NULL` означает «неизвестно». Модель встречи получает оба поля.

**Заполнение при сохранении записи.** Источник — `metadata.json` в папке встречи: `created_at` оттуда даёт реальное начало записи (файл пишется в момент старта), `duration_seconds` — фактическую длительность. Если файла нет или значение не разбирается: длительность из конца последнего сегмента, дата — текущий момент; если нет и этого — `NULL`.

**Отдача.** Команда списка начинает возвращать оба поля (RFC3339 и число, отсутствующие — не сериализуются вовсе). `created_at` и название остаются как были.

**Показ.** Форматеры даты и длительности: `18/11/2026, 14:32` и `42 min` / `1 h 23 min` / `< 1 min`; нет значения → `null`. Строка сайдбара: название ограничено двумя строками с троеточием, под ним вторая строка мелким серым с текстом `дата · длительность`, которая пропускает отсутствующие части и не рисуется вовсе, если нет обеих.

Ограничения: блок поискового совпадения `Match:` остаётся под новой строкой; иконка и hover-кнопки не меняются; свёрнутый сайдбар правок не требует.

## Критерии готовности

- [ ] Записываю встречу и останавливаю — в списке под названием `дата · длительность`, дата соответствует началу записи, а не моменту сохранения.
- [ ] Длительность совпадает с фактической длительностью записи.
- [x] Длинное название обрезается троеточием после двух строк.
- [x] Встреча без длительности показывает только дату, без разделителя; встреча без обеих — без второй строки.
- [x] При поиске блок `Match:` отображается под строкой с датой.
- [x] Миграция применяется к базе со старыми встречами, старые строки читаются без ошибок.
- [x] Тесты зелёные: миграции, сохранение записи, форматтеры, строка сайдбара.
