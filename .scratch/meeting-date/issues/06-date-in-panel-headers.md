# 06: Дата встречи в шапках панелей саммари и транскрипта

Type: task
Status: ready-for-agent
Blocked by: 02

## Что сделать

В правом верхнем углу открытой встречи появляется дата и время. Сейчас шапки обеих панелей — это центрированные строки кнопок, места для такого элемента нет вовсе.

- Над существующей строкой кнопок добавляется отдельная тонкая строка, прижатая вправо, с датой в формате `18/11/2026, 14:32`.
- Компоновка кнопок не меняется: они остаются по центру.
- Правило одинаково для панели саммари и панели транскрипта — при переключении вкладок дата не исчезает.
- Нет даты или она не разбирается — строки нет вовсе, без заглушек.
- Только дата и время, без длительности.

Ограничения: панели — контейнерные корни, соседние элементы прячут подписи контейнерными запросами; дата не должна ломать эти запросы и наезжать на кнопки в узком окне.

## Критерии готовности

- [ ] Открываю встречу — дата в правом краю шапки, кнопки по центру.
- [ ] Переключаюсь на вкладку транскрипта — дата на месте.
- [ ] Встреча без даты — шапка выглядит как раньше.
- [ ] В узком окне ничего не наезжает и не переносится.
- [ ] Компонентные тесты зелёные.
