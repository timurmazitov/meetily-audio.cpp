# 01: Единый тип элемента сайдбара

Type: task
Status: ready-for-agent
Blocked by: —

## Что сделать

Убрать дублирование объявления `SidebarItem`: сейчас интерфейс объявлен дважды — в провайдере сайдбара и в самом компоненте сайдбара, и любое новое поле приходится добавлять в оба места, иначе оно молча теряется.

- Объявить тип один раз и импортировать его во втором месте.
- Никаких изменений поведения: состав полей, рендер и поиск остаются прежними.

Это префактор: следующие срезы добавляют в этот тип поля даты и длительности.

## Критерии готовности

- [ ] Тип объявлен в одном месте, второй файл его импортирует.
- [ ] Поиск по транскрипту, правка названия и удаление встречи продолжают работать (они используют спред и фильтр по элементам).
- [ ] Существующие тесты зелёные; `tsc` без новых ошибок.
