# 05: Список упорядочен по дате встречи

Type: task
Status: ready-for-agent
Blocked by: 02, 03

## Что сделать

Список сортируется по дате встречи, а не по моменту появления строки в базе: `ORDER BY COALESCE(recorded_at, created_at) DESC`.

`COALESCE`, а не просто `recorded_at`: встреча без даты не должна уезжать в конец списка.

Ограничения: сортировка — часть ответа команды списка, чтобы порядок не пересчитывался на клиенте и не расходился между перезагрузками.

## Критерии готовности

- [ ] Импортирую архивную запись — она встаёт на историческое место, а не первым элементом.
- [ ] Свежая запись остаётся сверху.
- [ ] Встреча без даты не оказывается в конце списка.
- [ ] Тест сортировки зелёный.
