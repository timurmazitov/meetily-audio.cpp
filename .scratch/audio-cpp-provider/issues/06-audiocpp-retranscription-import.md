# 06: Ретранскрибация и импорт файлов через audioCpp

**What to build:** Провайдер `audioCpp` становится доступен во всех путях выбора движка транскрибации: пользователь может перетранскрибировать существующую встречу моделью audioCpp (например, сравнить качество с Whisper) и транскрибировать импортированный внешний аудиофайл через audioCpp. Поведение согласуется с живым пайплайном: те же сегменты, те же метаданные модели, диаризация применяется и здесь, если скачана модель.

**Blocked by:** 04 (Транскрибация встречи провайдером audioCpp)

**Status:** ready-for-agent

- [ ] В диалоге перетранскрибации встречи доступен провайдер `audioCpp` и его модели
- [ ] Перетранскрибация встречи через GigaAM заменяет транскрипт корректно, старые данные не портятся
- [ ] Импорт внешнего аудиофайла транскрибируется через audioCpp с тем же результатом, что и живой пайплайн
- [ ] Диаризация применяется к результатам перетранскрибации/импорта, если скачана модель Nemotron
- [ ] Ошибки (не загружена модель, сбой движка) обрабатываются как в живом пайплайне
