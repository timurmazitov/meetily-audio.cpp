# Ребрендинг приложения в Samobranka (samobranka.ai) без миграции данных

Приложение переименовано из Meetily (форк `Zackriya-Solutions/meeting-minutes`) в **Samobranka** / **samobranka.ai**. Ребрендинг полный: пользовательские строки, bundle identifier (`com.meetily.ai` → `ai.samobranka.app`), имя бинаря (`meetily` → `samobranka`), пути данных, env-переменные (`MEETILY_*` → `SAMOBRANKA_*`), артефакты CI и иконки. Версия 0.5.0 во всех манифестах сохранена. Атрибуция исходного проекта — только на уровне лицензии: `LICENSE.md` (MIT, Copyright Zackriya Solutions) не изменяется, в UI и README атрибуционный текст не добавляется.

## Considered Options

- **Косметический ребрендинг** (только пользовательские строки, идентификаторы сохранить): не ломает существующие установки, но продукт продолжал бы носить чужое имя в идентификаторе бандла, endpoint обновлений и путях данных. Отклонено — владелец бренда выпускает релизы под собственным именем.
- **Полный ребрендинг с миграцией данных** (перенос БД и настроек со старого identifier на новый): щадяще для существующих пользователей, но добавляет контур миграции и тестирования ради аудитории, которая у нового бренда отсутствует. Отклонено — продукт начинает историю с нуля.
- **Полный ребрендинг без миграции** (принято): смена идентификаторов целиком; старые установки не подхватываются, за исключением существующего legacy Homebrew-импорта, пути которого (`/opt/homebrew/var/meetily/…`, `/usr/local/var/meetily/…`) намеренно сохраняют старое имя.

## Consequences

- Bundle identifier изменён один раз и после первого публичного релиза samobranka менять его повторно нельзя без повторной потери данных — идентификатор считаем перманентным.
- Автообновление отключено: секция `plugins.updater` удалена из `tauri.conf.json` (endpoint смотрел на чужой репозиторий и мог подсунуть несовместимые обновления). Включение под собственный GitHub-контур — отдельная задача: новый endpoint + новая minisign-пара, permission `updater:default` вернуть в capabilities.
  - **Update (2026-11-17): выполнено.** Сгенерирована новая minisign-пара, секция `plugins.updater` с endpoint `timurmazitov/samobranka/releases` возвращена в `tauri.conf.json`, плагин зарегистрирован в `lib.rs`, permission `updater:default` восстановлен, `Cargo.lock` закоммичен. Осталось: добавить приватный ключ в секреты CI (`TAURI_SIGNING_PRIVATE_KEY`) и опубликовать первый релиз с `latest.json`.
- Секреты и переменные CI переименованы в `SAMOBRANKA_*`; перед первым релизом их нужно создать в настройках GitHub-репозитория (локально недоступно).
- Репозиторий и домен на момент решения не переименованы: URL в манифестах и документации указывают на планируемое расположение `timurmazitov/samobranka` и `https://samobranka.ai`; публикация — отдельным решением.
- Иконки регенерированы из временной заглушки (фиолетовый квадрат с «S»); настоящий логотип и скриншоты документации — отдельная задача.
- Контроль регресса — скрипт `scripts/check-brand.py`: репозиторный brand-lint с allowlist исключений (лицензия, legacy-пути импорта, скомпилированные sidecar-бинарники).
