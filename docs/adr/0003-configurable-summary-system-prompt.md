# 0003. Настраиваемый системный промпт саммаризации с перекрытием на уровне шаблона

Системный промпт финального отчёта сделан редактируемым: базовый — в настройках (вкладка Summary), плюс опциональный промпт в JSON шаблона, который при задании **полностью заменяет** базовый. Замена без конкатенации выбрана ради предсказуемости: «пустое поле = базовый, непустое = ровно этот текст». Промпт хранится с плейсхолдерами `{section_instructions}` и `{template}`, потому что инструкции секций и разметка шаблона исторически встроены внутрь системного промпта — наивная полная замена без плейсхолдеров молча отключила бы заполнение секций. Настраиваемым является только промпт финального отчёта: внутренние промпты пайплайна (чанкинг, комбайн, перевод, нормализация) остаются захардкоженными, иначе пользовательский промпт сломал бы двухпроходную схему «English base → перевод».

Подробности — в `docs/summary-system-prompt.md`.
