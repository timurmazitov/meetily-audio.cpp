# Samobranka

Словарь предметной области Samobranka: десктоп-приложение для записи встреч, транскрибации речи и генерации саммари. Термины, специфичные для предметной области записи/транскрибации встреч.

## Language

**Движок транскрибации (transcription engine)**:
Конкретная реализация распознавания речи, встраиваемая в приложение как модуль. Единственный локальный движок — transcribe.cpp (модуль `transcribe_cpp_engine`, GGUF-каталог моделей, режимы вычисления auto/vulkan/cpu). Диаризацию выполняет отдельный движок audio.cpp (модель Nemotron); он не является движком транскрибации.
_Avoid_: бэкенд, модель

**Провайдер транскрибации (transcription provider)**:
Выбранный в настройках движок транскрибации — значение конфигурации (единственный локальный провайдер — `transcribeCpp`), а не сам модуль.
_Avoid_: engine, бэкенд

**Речевой сегмент (speech segment)**:
Непрерывный кусок речи, выделенный VAD из сырого потока, с временными метками начала/конца.
_Avoid_: чанк (в UI), кусок

**Диаризация (diarization)**:
Отдельный этап обработки встречи — второй после транскрибации: атрибуция фрагментов речи конкретным участникам встречи (спикерам) поверх готового транскрипта. Не является свойством движка распознавания речи и не зависит от выбранного провайдера транскрибации; выполняет её движок audio.cpp (модель Nemotron-3 Diarization) при установленной модели диаризации.
_Avoid_: распознавание спикеров, speaker identification

**Спикер (speaker)**:
Участник встречи, чья речь атрибутирована диаризацией. Идентифицируется порядком появления (speaker_0, speaker_1, …), без привязки к реальной личности.
_Avoid_: участник, говорящий

**Имя спикера (speaker name)**:
Реальное имя человека, сопоставленное спикеру встречи вручную через глобальный справочник людей. Не является меткой диаризации и не переименовывается.
_Avoid_: метка спикера, имя диаризации

**Справочник людей (people directory)**:
Глобальный перечень людей, из которого выбирается имя спикера. Не принадлежит ни одной встрече: одно и то же имя доступно во всех встречах, а человек, на которого больше не ссылается ни одна встреча, из справочника удаляется. В панели Speakers список выбора показывает весь справочник по алфавиту, а не ограниченную подборку «самых частых» имён.
_Avoid_: список спикеров, контакты, база людей

**Поворот спикера (speaker turn)**:
Непрерывный интервал речи одного спикера с метками начала/конца — атомарный вывод диаризации.
_Avoid_: реплика, диалоговый ход

**Дата встречи (meeting date)**:
Момент, когда встреча состоялась. Для записанной встречи — начало записи, для импортированной — момент импорта. Хранится в отдельном поле, отличном от времени появления строки в базе; при отсутствии не подменяется текущим моментом. Пользователь может исправить её вручную в окне редактирования встречи, и это то же поле, а не копия.
_Avoid_: дата создания, `created_at`, дата записи (для импортированной встречи), дата импорта (для записанной)

**Длительность встречи (meeting duration)**:
Продолжительность встречи в секундах: для записи — фактическая длительность записи, для импортированной — длительность исходного аудиофайла. Отсутствие значения выражается пустым значением, а не нулём.
_Avoid_: длина, продолжительность записи

**Экспорт транскрипции (transcript export)**:
Сохранение текста транскрипции в файл через системный диалог сохранения. Содержимое файла идентично тексту, копируемому кнопкой копирования (включая разметку спикеров); после успешного экспорта полный путь к файлу копируется в буфер обмена. Имя файла по умолчанию — `<YYYYMMDD>-<название_встречи>-transcript.txt`, где дата — локальная дата встречи.
_Avoid_: save, выгрузка

**Экспорт саммари (summary export)**:
Сохранение саммари в markdown-файл через системный диалог сохранения с фильтром «Markdown Files». Содержимое файла идентично тексту, копируемому кнопкой копирования саммари, с единственным отличием: строка метаданных в файле — `**Exported on:**`, в буфере — `**Copied on:**`; экспортируется текущее состояние редактора, включая несохранённые правки. После успешного экспорта полный путь к файлу копируется в буфер обмена. Имя файла по умолчанию — `<YYYYMMDD>-<название_встречи>-summary.md`, где дата — локальная дата встречи.
_Avoid_: save, выгрузка, download

## Саммаризация

**Базовый системный промпт (base system prompt)**:
Системный промпт для генерации саммари по умолчанию, редактируемый в настройках (вкладка Summary). Используется для любого запроса саммаризации, если у шаблона не задан свой системный промпт.
_Avoid_: дефолтный промпт, глобальный промпт

**Системный промпт шаблона (template system prompt)**:
Необязательный системный промпт, заданный в конкретном шаблоне. При задании полностью заменяет базовый системный промпт; при отсутствии используется базовый.
_Avoid_: свой промпт, кастомный системный промпт

**Дополнительный контекст саммаризации (custom prompt)**:
Свободный текст, который пользователь указывает при генерации конкретного саммари. Передаётся модели вместе с транскриптом как часть запроса; не является системным промптом и не перекрывает ни базовый, ни шаблонный промпт.
_Avoid_: пользовательский промпт, user prompt, свой промпт
